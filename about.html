Website Overview

This website demonstrates basic HTML, CSS, and JavaScript concepts through a peanut butter and jelly sandwich theme. It combines static content, user interaction, external data, state management, and performance improvements into a single web application.

Using External Data

This website demonstrates how JavaScript can retrieve and display external JSON data using the Fetch API.

Data is requested from an external source and does not arrive immediately. After the data is received, specific values are extracted and displayed on the page. This demonstrates asynchronous behavior and the flow of data from request, to response, to display.

Instead of showing raw JSON data, the application selects useful information and formats it clearly for users.

State Management

The website demonstrates state management using JavaScript. State allows the application to store information, update it when users interact with the page, and immediately reflect those changes in the user interface.

Users can change the sandwich counter through button clicks. The application keeps the displayed information synchronized with the current value at all times.

Performance Improvements

The application was improved to reduce unnecessary work and improve efficiency. User information from the external API is assembled first and then displayed with a single page update instead of repeatedly updating the page for each user.

The website also displays only a limited set of users from the API rather than showing every available record at once. This keeps the interface cleaner and reduces the amount of content that must be rendered.
